📋 설문조사 생성

질문을 여러 개 추가할 수 있어. 생성한 설문은 수정할 수 없어.

익명 설문은 응답 내용에 이름과 학번을 저장하지 않아. 실명 설문은 응답자 정보가 수집된다는 점을 응답자에게 알려야 해.

🗂 생성한 설문조사

생성된 설문의 응답 결과를 확인할 수 있어. 설문 내용은 수정할 수 없어.

🔗 메인 화면 링크 설정

주소를 비워 두면 메인 화면에 해당 버튼이 나타나지 않아.

👥 하위 관리자 지정
